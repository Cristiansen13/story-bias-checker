Five gaps, five design answers

GapWhat is missingResponse in this project
G1 Recognition is not productionBenchmarks test whether a model prefers a stereotype it is shown, not what it writes when freePremises that leave every attribute open; the written story is the unit of analysis
G2 Proxies miss castingSentiment and regard stay neutral when every nurse is a woman and every cleaner an immigrantHuman-perceived labels, casting split from substantive stereotypes, lexical analyzers
G3 One axis, one familyMostly gender only, one often older model, each study with its own prompts and samplingThe same 89 premises for several families and sizes, one sampling setup
G4 Unstated annotation rulesWhether casting counts is left to each annotator; LLM-annotator reliability is rarely reportedWritten casting criteria, blind batches mixing all models, repeated stories, Cohen’s κ
G5 Opaque detectorsA score without the sentence that triggered it, so review is slowEvidence sentences shown in a human-in-the-loop review queue
What the existing work misses comes down to five gaps. First, benchmarks measure recognition, not what a model writes when it is free to choose. Second, automatic proxies like sentiment miss casting: a story where every nurse is a woman reads as neutral. Third, most studies cover one axis and one model family, with incomparable settings. Fourth, annotation rules, especially whether casting alone counts, are left unstated, so labels drift. Fifth, detectors give scores without evidence. The right column shows how our design answers each one.
