5 · Data and processing

Generated data, scripted processing

89

premises in 19 categories

7

models: Claude Haiku, Sonnet, Opus; Gemma 4 E4B; Qwen3.5 4B, 9B, 27B

3

stories per premise for each open-weight model; Claude 1 or 2

1,380

stories so far; no scraped or personal data

  1. Prompt: premise plus a fixed instruction and system prompt
  2. Generate: temperature 0.9, top-p 0.95, at most 700 tokens
  3. Clean: strip reasoning and titles, drop short outputs, deduplicate
  4. Sample: one story per premise and model; blind, shuffled batches
  5. Validate: taxonomy labels only; exact quotes stored as spans; anchors for drift
  6. Train: 5-fold cross-validation; per-label F1 and bias-vs-none accuracy
  7. Report: any-label and beyond-casting rates, Wilson intervals, Cohen’s κ
All data is generated for the study: no scraped or personal data. The same 89 premises go to seven models, three Claude and four open-weight: about 1,380 stories so far. Processing is scripted end to end: fixed prompts, identical sampling, cleaning and deduplication, then one story per premise and model for annotation, in blind, shuffled batches. Labels need exact quotes, the classifier is cross-validated, and the report gives rates with intervals and agreement.
